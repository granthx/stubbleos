# Machine Scheduler Agent

## Purpose
The Machine Scheduler agent allocates crop residue clearing machinery (Happy Seeders, Super Seeders, balers, and rakes) across farm fields. It supports both centralized global optimization (OR-Tools CP-SAT) and decentralized market coordination (Contract-Net protocol auction with fairness tie-breaking).

## Critical Invariant
**The LLM only explains and negotiates around the optimizer output, and NEVER changes assignments.**
Assignments, schedules, and machine routings are generated strictly by the CP-SAT solver or Contract-Net coordinator. The LLM receives read-only metrics and produces natural-language explanations for operators and farmers.

## Inputs
- `MachineSchedulerInput`:
  - `jobs`: List of `JobRequest`s (field ID, farmer landholding class, area, harvest readiness, sowing deadline, location, required machine types).
  - `machines`: List of `MachineResource`s (capacities, operating costs, current locations, availability).
  - `mode`: Scheduling mode (`cpsat` or `auction`).
  - `config`: Solver parameters (`SchedulerConfig`).
  - `current_hour`: Current simulation/wall-clock hour.
  - `request_explanation`: Boolean flag indicating whether to invoke LLM explanation.

## Outputs
- `MachineSchedulerOutput`:
  - `assignments`: Exact list of `ScheduleAssignment` records (field ID, machine ID, start hour, completion hour, is on-time, cost).
  - `unassigned_job_ids`: List of field IDs not yet assigned.
  - `objective_value`: Coverage and timeliness objective score.
  - `solver_status`: Status from optimizer (`OPTIMAL`, `FEASIBLE`, `INFEASIBLE`).
  - `explanation`: Auditable explanation text generated by the agent.
  - `audit_logs`: Detailed conflict resolution logs from tie-breaks.

## Failure Modes & Escalation
- `INFEASIBLE` or `ERROR` solver status: Falls back to greedy assignment or unassigned status; flagged to Orchestrator.
- Timeout: CP-SAT honors `time_limit_seconds` and returns the best feasible solution found within the deadline.
- Machine Shortage: Escalated to Orchestrator for conflict resolution and priority ranking.
