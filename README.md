# StubbleOS

An autonomous coordination layer that connects farmers, machinery owners, logistics providers and straw buyers so that paddy straw in Punjab/Haryana is cleared before the wheat-sowing deadline without burning, with auditable impact records.

> **Status: simulation-first MVP, Phase 1 of 8 (foundation).** Nothing here is deployed, piloted or validated with real farmers. Any data is synthetic and labeled as such. Impact records are *indicative, not registry-verified*.

## Results

No results yet. The results table is generated by a script in Phase 8 from seeded simulation runs (`make results`, not yet implemented). Nothing in this repo reports numbers that were not produced by a reproducible run.

## Phase 1 contents

Typed config, shared domain types, injectable clock and seeded IDs, PII redaction and pseudonyms, typed event bus (in-memory and Redis), retry/timeout utility, LLM wrapper (`FakeLLM`, Anthropic adapter, versioned prompt registry), full database schema (`core` and `pii` schemas) with a baseline migration, consent ledger and hash-chained audit log, a health/metrics API, docker-compose and CI.

Not yet built: simulator (P2), optimizers and auction (P3), agents and orchestration (P4), geospatial and weather (P5), Farmer Voice and negotiation (P6), full API and dashboard (P7), experiments and remaining docs (P8). `make demo` intentionally exits with a message until then.

## Quickstart

```bash
uv sync --all-extras          # first run creates uv.lock; commit it
cp .env.example .env
make lint typecheck test      # unit tests, no external services
make up                       # postgres+postgis, redis, migrations, api on :8000
make test-int                 # integration tests (needs `make up`)
curl localhost:8000/readyz
```
